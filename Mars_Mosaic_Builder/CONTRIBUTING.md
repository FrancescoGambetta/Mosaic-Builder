# Contributing to Mosaic Builder

First off, thank you for considering contributing to Mosaic Builder! 🎉

## 🐛 Found a Bug?

1. **Check if it's already reported**: Search existing [issues](https://github.com/YOUR_USERNAME/mosaic-builder/issues)
2. **Create a new issue**: If not found, open a new issue with:
   - Clear title
   - Steps to reproduce
   - Expected vs actual behavior
   - Screenshots if applicable
   - Your environment (OS, Python version, OpenCV version)

## 💡 Have a Feature Request?

1. Open an issue with the `enhancement` label
2. Describe the feature and why it would be useful
3. Provide examples if possible

## 🔧 Want to Contribute Code?

### Getting Started

1. Fork the repository
2. Clone your fork:
   ```bash
   git clone https://github.com/YOUR_USERNAME/mosaic-builder.git
   ```
3. Create a new branch:
   ```bash
   git checkout -b feature/your-feature-name
   ```

### Making Changes

1. Make your changes
2. Test thoroughly
3. Follow the existing code style
4. Add comments for complex logic
5. Update README.md if needed

### Submitting Changes

1. Commit your changes:
   ```bash
   git add .
   git commit -m "Add feature: brief description"
   ```
2. Push to your fork:
   ```bash
   git push origin feature/your-feature-name
   ```
3. Open a Pull Request on GitHub

### Pull Request Guidelines

- Clear title describing the change
- Reference any related issues (#123)
- Describe what changed and why
- Include before/after examples if applicable

## 📝 Code Style

- Use meaningful variable names
- Follow PEP 8 guidelines
- Add docstrings to functions
- Keep functions focused and concise
- Comment complex algorithms

## ✅ Testing

Before submitting, test with:
- Different image formats (jpg, png, tif)
- Various image sizes
- Photos with and without EXIF data
- Different overlap scenarios

## 🤝 Code of Conduct

- Be respectful and inclusive
- Provide constructive feedback
- Focus on the code, not the person
- Help others learn and grow

## 📧 Questions?

Feel free to open an issue with your question!

---

Thank you for contributing! 🙏
